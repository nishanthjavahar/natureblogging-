# WildGuard

WildGuard is a full stack MERN wildlife blogging platform designed to spread awareness about wildlife conservation and nature protection.

## Features
- User blog viewing
- Admin authentication
- Add/Edit/Delete blogs
- Wildlife image uploads
- Search functionality
- Responsive UI

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB Atlas
- Multer
